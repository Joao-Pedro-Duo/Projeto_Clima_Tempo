# Atribuições e Créditos de Terceiros

Este projeto utiliza serviços, bibliotecas e componentes de terceiros.

## Open-Meteo

Serviço utilizado para geocodificação e consulta dos dados meteorológicos.

- Serviço: Open-Meteo
- Dados: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Uso neste projeto: finalidade educacional e não comercial
- Atribuição: Dados meteorológicos fornecidos por Open-Meteo.com

Os dados apresentados pela aplicação podem sofrer alterações de
formatação, incluindo arredondamento de temperaturas, tradução das
condições meteorológicas e formatação de datas.

Mais informações:

https://open-meteo.com/

https://creativecommons.org/licenses/by/4.0/
